# Support

- Use GitHub Discussions or an issue for setup questions, reproducible bugs, and feature proposals.
- Search existing documentation and issues before opening a new report.
- Include application version, operating system, deployment method, sanitized logs, and reproduction steps.
- Do not include Gmail addresses, tokens, authorization URLs, email bodies, databases, or reports.
- Report vulnerabilities privately according to `SECURITY.md`.

The project is maintained on a best-effort basis and has no commercial support or response-time commitment.
